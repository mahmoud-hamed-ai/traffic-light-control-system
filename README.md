🚦 Traffic Light Control System

📌 Project Overview

An Arduino-based Traffic Light Control System designed to simulate a real traffic light system using six LEDs arranged in two columns.

The system controls traffic signals in two directions, allowing each direction to operate in an organized sequence.

🛠️ Components Used

* Arduino Uno
* 6 LEDs:
    * 2 Red LEDs
    * 2 Yellow LEDs
    * 2 Green LEDs
* 6 Current-Limiting Resistors
* Breadboard
* Jumper Wires

🔌 Pin Connections

Traffic Light	Arduino Pin
Column 1 - Red	D2
Column 1 - Yellow	D3
Column 1 - Green	D4
Column 2 - Red	D5
Column 2 - Yellow	D6
Column 2 - Green	D7

💻 Programming

* Language: C++
* Platform: Arduino IDE
* Microcontroller: Arduino Uno
